# macOS 免费内测版安装

这是搭手 macOS 免费内测版的安装方法。这个版本还没有购买 Apple 开发者签名，所以 macOS 第一次打开时可能会提醒“无法验证开发者”。这是预期提示，不是安装失败。

## 安装

1. 从 [搭手 GitHub Releases](https://github.com/winston003/dashou-releases/releases/latest) 下载 **Mac Apple Silicon** 或 **Mac Intel** 安装包。
2. 双击下载的 `.dmg` 文件。
3. 把 **Dashou** 图标拖到 **Applications（应用程序）**。

![搭手 macOS 安装窗口](images/macos-dmg-install-window.jpg)

4. 关闭安装窗口，并在 Finder 左侧推出搭手安装盘（如果它还显示在那里）。
5. 打开“应用程序”文件夹，找到 **Dashou**。
6. 第一次打开时，不要直接双击：对 **Dashou** 点右键（或按住 Control 点击），选择 **打开**。
7. macOS 再次询问时，点击 **打开**。

只需要这样确认一次。之后通常可以像其他应用一样直接打开搭手。

## 如果没有看到“打开”

确认 Dashou 已经被拖到了“应用程序”文件夹，然后再对“应用程序”里的 Dashou 点右键。如果仍然打不开，请把提示窗口截图发给客服，不要关闭 Mac 的整体安全检查，也不需要打开终端输入命令。

## 打开后怎么用

打开搭手后，按 [搭手：安装后怎么连接 ChatGPT](GETTING_STARTED.md) 操作：点击“开始使用搭手”，等待准备完成，选择一个或多个文件夹，再跟着客户端的 1/3 → 2/3 → 3/3 连接 ChatGPT。

关闭窗口只会把搭手收起到 macOS 顶部菜单栏，不会停止服务。要真正停止搭手，请从顶部菜单栏选择“退出搭手”。

## 说明

免费内测版的首次确认是 macOS 对未公证应用的正常保护。它不会要求你输入 Apple 账号、网络地址、Tunnel Token 或其他技术信息。未来完成 Apple 签名和公证后，安装步骤会进一步简化，不需要改变搭手的使用方式。
